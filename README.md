# 🎓 Exercise 46/50 - First Database

Model a database table to store information about used cars available for sale at a car dealership. Define a suitable structure to organize and manage vehicle data.

## 🎯 Assignment

Design the structure of a database table to store all the relevant information about used cars offered for sale by a car dealership.

The goal is to identify the data needed to describe each vehicle and define an appropriate table structure to store it.

Consider the information required to identify, describe and manage each car in the dealership's inventory.

## 💡 What I Learned

- Understanding the fundamentals of relational databases.
- Designing a database table based on real-world requirements.
- Identifying relevant data fields for an entity.
- Organizing structured information into a database schema.
- Understanding how to model real-world objects in a database.
